# Documentação do yuruna-project em português (Brasil)

Esta pasta contém a tradução para português do Brasil dos documentos de
introdução deste repositório. O inglês continua sendo a fonte de verdade:
cada arquivo aqui é uma cópia traduzida, e o original em inglês nunca é
alterado por uma tradução.

> **Revisão por documento.** O manifesto de traduções do framework registra
> a revisão aceita para cada arquivo. `tools/Test-DocTranslation.ps1`, no
> repositório `yuruna`, verifica esse registro e mudanças no original em
> inglês. Alterações posteriores na tradução precisam de nova revisão
> humana; a verificação de integridade não substitui essa revisão.

## Para quem revisa

Nomes de arquivos, comandos, chaves de configuração, identificadores e
todo o conteúdo dentro de blocos de código permanecem em inglês de
propósito -- o operador precisa digitá-los exatamente como aparecem no
sistema.

A interface do próprio aplicativo de exemplo (em `example/*/components/`)
não faz parte deste conjunto: ela pertence ao aplicativo, não à interface
de operação do Yuruna.
